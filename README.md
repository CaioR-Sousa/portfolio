# 💼 Portfólio Front-End

Bem-vindo ao meu portfólio de projetos! 🚀

Este projeto foi desenvolvido com o objetivo de reunir em um único lugar as aplicações que desenvolvi durante meus estudos em desenvolvimento Front-End, demonstrando minha evolução em HTML, CSS e JavaScript.

## 📖 Sobre o projeto

O portfólio apresenta uma interface moderna e responsiva, onde cada projeto é exibido em um cartão contendo uma imagem, título e links para visualização das funcionalidades e do código-fonte.

As informações dos projetos são carregadas dinamicamente a partir de um arquivo JSON utilizando a API `fetch()`, permitindo uma estrutura organizada e fácil de manter.

## ✨ Funcionalidades

* Layout responsivo para diferentes tamanhos de tela.
* Cards organizados em Grid Layout.
* Efeitos de hover nos cartões e botões.
* Modal com informações detalhadas de cada projeto.
* Carregamento dinâmico dos dados utilizando `fetch()`.
* Leitura de dados em formato JSON.
* Interface moderna com tema escuro.
* Navegação simples e intuitiva.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (ES6+)
* Fetch API
* JSON
* Flexbox
* CSS Grid

## 🎯 Objetivo

Além de servir como meu portfólio pessoal, este projeto foi criado para consolidar conhecimentos em JavaScript moderno, especialmente no consumo de dados assíncronos utilizando `fetch()`.

Conforme novos projetos forem desenvolvidos, eles poderão ser adicionados facilmente ao portfólio apenas atualizando o arquivo `projetos.json`, sem necessidade de alterar a estrutura principal da página.
